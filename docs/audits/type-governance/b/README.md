# Type governance PR2: B1–B10 caller audit

Baseline: main `f853870a8890b53b271e5765c360d9c7e4dc50ab` (PR1 #906).

| Candidate | Verified contract and outcome |
| --- | --- |
| B1 | ActiveClient legacy method parameters reuse GeminiProviderClient. Results remain opaque Promise<unknown>: production currently installs an ApplicationProvider (listConversations/fetchConversationDetail) in syncEngine, and ContentContext only consumes abort. Existing active_client_contract tests deliberately inject an object/array from the old optional methods. Pretending those results are a validated pagination/detail result would be false. The compatibility index signature stays unchanged. |
| B2 | Retained. Actual registerTimer calls save browser timers and MutationObserver; clearTimer also supports abortable objects and Node-style timer handles. A simple union cannot type the existing property probes plus timer fallback without changing guards/branch evaluation or asserting capabilities that were not checked. |
| B3 | Typed public on/emit overloads for existing ContentEvent names. Payload tuples come only from actual emit calls: credentials nullable, abort no arguments, language string, dev mode boolean. reset/scanStart/scanEnd have no current producers, so their arguments stay unknown[]. The original heterogeneous listener storage and implementation signatures are retained; no event or payload was invented. |
| B4 | Typed metadata upsert dependency and local stream-complete item. Network-detail copies updatedAt into timestamp: updatedAt already permits a string, unlike ConversationMergeInput.timestamp. MessageBridgeConversationInput therefore derives that field from both existing declarations; no conversion or runtime field read changed. syncEngine's actual upsert accepts these deltas, and its existing merge/time handling remains untouched. |
| B5 | Constructor/root capability uses native FileSystemDirectoryHandle plus optional existing DirectoryHandle permission methods, matching live-save's native handle and options' directory controller. Null/undefined constructor inputs remain allowed for the existing throwing guard; the factory derives its input from that signature. Content reuses WriteFileContent and null/undefined failure behavior; options use consumed base64/compression fields and opaque passthrough keys. Internal initialized batch handle, traversal and init result remain unchanged: narrowing these would require proving the post-await state and legacy mocks' recursive capabilities. No native API declarations were loosened. |
| B6 | ZIP content size probes, write options and progress metadata are typed. Bundled lib/jszip.min.js is JSZip 3.10.1 and accepts STORE/DEFLATE, base64 and compressionOptions.level; production uses base64 and tests cover compression/options passthrough, Blob/byte counting, stream fallback and injected constructors. zip/folder and dynamic constructor remain unchanged: __resolveModule('JSZip', null), global self.JSZip and require fallback are unverified injection seams, not statically verified JSZip instances. No assertion or new module dependency was introduced. |
| B7 | PDF DI fields reuse PreparePdfItemContext, which already derives asset callbacks from AssetPipelineOptions and supports partial Takeout and acquireAssetBytes test seams. Returned bridge/network values remain unknown at their existing boundaries. |
| B8 | Persistence adapter arguments derive from actual generic StorageService methods specialized to StandardExportRecord. Ignored adapter return values stay Promise<unknown>, preserving void-returning test seams. onItemExported reuses FinalizeExportOptions. Conversation remains unchanged: completion accepts native and legacy metadata plus tests' count-only numeric messages; narrowing it to Conversation/TrustedDomain would falsely claim a complete body and force changes to timestamp helpers, primitive probes or callers. No repeated schema validation added. |
| B9 | cred uses Partial<GeminiCredentials> (nullable) and getCredStorage reuses CredentialManager's actual return type. loadCredMap deliberately stays unchanged: the manager returns Record<string, unknown>, and retryPolicy mutates map[sid].at/bl without a value guard. Typing it as validated credentials or adding checks would violate this static-only task. Raw credential storage stays untrusted. |
| B10 | Pipeline selection is the object subset of UIExportOptions.selected, matching ListView.getSelected's Conversation[] and the existing unconditional chat.id access; the controller's wider string support is not assigned to this narrower UI caller. dirHandle/newHandle reuse UIExportOptions; directory picker, permission controller and existing restore behavior are unchanged. No raw storage value was asserted valid. |

Independent complete lint JSON snapshots are stored as gzip files; lint-comparison.json contains every rule/file/severity before and after. Warnings: 1,671 → 1,532 (-139); errors remain 0, and no rule/file category increases. No configuration, exemptions, non-null assertions, unsafe casts or fake guards were added.

All nine modified TS files have byte-identical esbuild ES2022 output versus baseline. Type-check passes; full npm test and CI outcomes are recorded in the PR. Existing writer injection, completion persistence/callback failure, stream start/complete, PDF assets/Takeout, selection and directory tests are included in the full gate. No runtime trigger for live Tier2 was introduced; parser/interception/sorting/Takeout behavior is unchanged.
