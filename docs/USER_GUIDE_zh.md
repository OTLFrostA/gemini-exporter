# Gemini Exporter · 使用指南

[← 返回 README](../README_zh.md) · [English](./USER_GUIDE.md)

Gemini Exporter 将支持的 Google Gemini 对话保存到本地，**不提供云端托管备份或云同步服务**。

## 导出格式与保存方式

| 格式 | 适用场景 |
| --- | --- |
| **Markdown**（`.md`） | Obsidian、Logseq、笔记、可读的长期归档 |
| **HTML**（`.html`） | 浏览器离线阅读、公式排版和亮暗主题 |
| **PDF**（`.pdf`） | 阅读与分享；通过本地 Typst/WASM 编译 |
| **JSON**（`.json`） | 结构化数据备份与程序处理 |

可获取的图片与文件附件可能随 Markdown、HTML 或 JSON 一起保存到 `assets/`、`files/`。PDF 会按需嵌入图片，原始文件附件也可能作为独立文件输出。

工作台提供**浏览器下载**和**保存到本地文件夹**两种方式。浏览器下载涉及多个文件时自动打包 ZIP；本地文件夹模式直接写入各个文件。大批量导出通常更适合授权本地目录，避免浏览器下载时在内存中打包大 ZIP。

## 导出当前对话

1. 登录并打开 [Gemini](https://gemini.google.com) 中的一篇对话。
2. 在插件弹窗选择 **Markdown、PDF、HTML 或 JSON**。
3. 点击**导出当前对话**，通过浏览器下载保存。

## 批量备份

1. 在弹窗打开**工作台**，点击**同步会话**。
2. 搜索或筛选已扫描到的会话，勾选需要导出的条目。
3. 选择格式和输出位置；使用本地文件夹时需先选择目录并授权。
4. 点击**导出选中**。工作台会显示导出成功、有更新、失败或附件问题等状态。

**扫描不等于文件备份。** 同步只更新当前可访问会话的本地目录；**导出选中**才会创建备份文件。之后扫描不到的旧对话，不会仅因此从本地归档中删除。

**跳过已导出**仅跳过最近一次完整导出、格式一致且已知来源没有更新的会话。需要其他格式或来源已经改变时，请重新导出。

## Markdown 实时保存

Gemini 回复完成后，可自动更新已授权目录中的 Markdown 文件。

1. 在工作台选择**保存到本地文件夹**，点击**选择文件夹**并授权。
2. 将格式设为 **Markdown (.md)**。
3. 在本地文件夹卡片内开启**实时保存**。

切换到**浏览器下载**或非 Markdown 格式时实时保存会**暂停**，开启偏好不会清除。浏览器重启导致目录权限失效时，需要重新授权。

## 通过 Google Takeout 补全历史

1. 从 [Google Takeout](https://takeout.google.com/settings/takeout/custom/gemini) 下载 Gemini 归档。
2. 在工作台选择归属账号，导入**原始 ZIP**（不需要手动解压）。
3. 选择导入的对话并正常执行导出。

Takeout 可以补充线上扫描无法获取的旧对话，但不能保证恢复已删除或已经过期的所有附件。

## 常见问题

**需要 API Key 或 Gemini 付费订阅吗？** 不需要。插件使用浏览器已有的 Gemini 登录会话；实际可读取的历史取决于账号及 Gemini 服务。

**ZIP 选项去哪里了？** ZIP 现在是浏览器多文件下载时的自动打包方式，并非独立导出格式；本地文件夹直接写入文件。

**实时保存可以输出 PDF/HTML 吗？** 暂不支持，实时保存仅支持 Markdown + 已授权本地文件夹。

**附件为什么没有保存？** 部分图片与文件链接可能失效。插件可提示检测到的资源问题，但无法还原 Gemini 不再提供的文件。

**PDF 为什么请求读取字体？** 本地 PDF 引擎有时需要 Chrome 的 Local Font Access 权限使用本机字体，尤其是中文等非拉丁文字。PDF 仍在本机编译。

**能导出 ChatGPT、Claude 或 Grok 吗？** 源码版实验性支持 ChatGPT 工作台扫描与导出：打开 ChatGPT 并登录，点击**连接 ChatGPT**并授予可选的网站访问权限，然后同步、导出。ChatGPT 暂不支持弹窗导出与实时保存。Claude 和 Grok 尚未实现。

**ChatGPT 问卷、交互卡片怎么导出？** 完整保留来源提供的 Markdown fallback，不因含有动态语法就把文字导出标为不完整。循环生成的表单还会从模板引用的字面量数组中补充题干和选项，不执行组件代码。动态组件没有可用 fallback 时，仍会标为不完整，因为仅提取字面量不能证明文字已全部恢复。按钮保存为文字，导出文件不还原交互状态、不提交问卷或执行 ChatGPT 操作；已选答案和计算结果只有在 fallback 或后续对话消息中存在时才会保留。
