How do I export my entire Gemini chat history?+

Install Gemini Exporter from the Chrome Web Store, authorize access to Gemini, and open the extension’s Workbench. Click Sync All to scan the available conversation list, select all conversations, choose a format and destination, then click Export selected. Sync All discovers conversations; Export selected creates the actual backup files.

Can I export thousands of Gemini conversations if the website doesn't load my full history?+

Yes. For very large histories, or when Gemini's online conversation list stops loading older chats, download your official Google Takeout Gemini archive. In the Workbench, choose the matching Gemini account and import the original ZIP file without extracting it. Then select and export the imported conversations. Takeout supplements online scanning, although deleted or expired content may not always be recoverable.

My bulk export is slow. Can I stop and resume it later?+

For a large backup, select Save to local folder instead of Browser download. Files are written directly to the folder, so the extension does not have to assemble a large browser-download ZIP in memory. You can stop and start another export later. Leave Skip exported enabled to skip completed exports of the same format when their source conversations are unchanged; interrupted or changed conversations can be exported again. You may need to reauthorize the folder after restarting Chrome.

How does automatic backup or Live Save work?+

In the Workbench, choose Save to local folder, authorize a folder, select Markdown (.md), and turn on Live Save. The extension updates the local Markdown backup when Gemini finishes a new reply during an active browsing session. This is not a cloud synchronization service, and it does not keep running after your browser is closed.

Which file formats can I export my Gemini conversations to?+

Choose Markdown, PDF, HTML, or JSON for individual conversations or batches. Markdown is useful for notes, HTML and PDF for reading, and JSON for structured archives. Browser downloads bundle multiple files into a ZIP automatically; Save to local folder writes files directly.

Can I save generated images, uploaded files, and other attachments?+

The exporter includes images and attachments where the source platform still makes them accessible. Some generated images or uploaded files can expire or become unavailable, in which case they cannot be reconstructed. The extension reports detected resource problems rather than pretending a partial export is complete.

Is Gemini Exporter free, private, and open source?+

Yes. The extension is free and open source, with no exporter subscription, telemetry, account signup, or API key. Export processing happens in your browser, and resulting files stay on your device. The extension uses your signed-in Gemini session to request your conversations from Gemini, but does not send their contents to a developer-operated server. You can review the source code and privacy policy.

How do I export just one Gemini conversation?+

Open the conversation in Gemini, click the extension popup, choose Markdown, PDF, HTML, or JSON, then select Export Current Conversation. You don't need to scan your entire history to save a single chat.

Can I import my official Google Takeout ZIP without unzipping it?+

Yes. Download the original Gemini archive from Google Takeout. Open the Workbench, select the destination Gemini account, and import the ZIP directly. Imported conversations can then be selected and exported in the same formats as online conversations.

Does it support ChatGPT, Claude, or Grok?+

The published Chrome extension currently supports Google Gemini. ChatGPT, Claude, and Grok support is being developed and may be available experimentally in source builds. We don't present those integrations as released until they are ready for general use.
